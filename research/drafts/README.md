# Unverified research drafts

Files in this directory are retained for internal review and are not copied into
the public site. Do not move a report into `public/downloads/` until its source
data, methodology, denominators, and limitations have passed the manual
benchmark publication gate.

`state-of-design-systems-unverified.pdf` was removed from the public download
path because its quantitative claims did not have reproducible supporting data.
